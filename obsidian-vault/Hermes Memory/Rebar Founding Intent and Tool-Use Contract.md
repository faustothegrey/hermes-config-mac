# Rebar — Founding Intent and Tool-Use Contract

**Status:** Canonical charter stored with the Capability-Reuse/Rebar skill.

The project charter now explicitly records the observation that created Rebar: Hermes repeatedly regenerated complete HMP `curl` commands through `terminal` even though the transport procedure was stable and only the payload changed.

Rebar's invariant is:

> Before the model regenerates an operation through a generic tool—especially terminal or generated Python—it checks for a reviewed reusable harness, prefers that harness when compatible, and makes the decision visible.

The charter defines:

- the HMP/curl founding example;
- the pre-tool operation-specific lookup contract;
- reuse, rejection, and no-harness outcomes;
- Observe bubble semantics;
- safety and identity requirements;
- real-path acceptance criteria;
- explicit non-goals.
